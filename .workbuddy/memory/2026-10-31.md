- 关键教训：本机 git 全局 http.proxy=127.0.0.1:10808(V2RayN)常失效；直连 github.com:443 也会超时(api.github.com 却通)；正确姿势是用沙箱自身透明代理(env http_proxy 指向 127.0.0.1:<动态端口>，如62917)：git -c http.proxy=$P -c https.proxy=$P push。端口每会话会变，从 env 读。

- 推送坑(重要)：github.com:443 直连超时 + 沙箱代理 CONNECT 502，但 api.github.com 通。解决：用 GitHub Git Data API 推送（git credential fill 取 token → blob/tree/commit/ref 四步）。注意 API 生成的 commit SHA 与本地不同（committer 身份不同），内容一致；网络恢复后需 git fetch && git reset --hard origin/main 对齐，避免后续 push 分叉。
